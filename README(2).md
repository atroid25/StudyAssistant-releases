# StudyAssistant

**Приложение для Windows, которое помогает превращать учебные материалы в конспекты и карточки для повторения.**

Этот репозиторий предназначен для распространения установщиков StudyAssistant и описаний изменений. Исходный код приложения здесь не размещается.

## Скачать

Перейдите в раздел [Releases](https://github.com/atroid25/StudyAssistant-releases/releases), выберите последний стабильный выпуск и скачайте **StudyAssistant-Setup.exe** из списка **Assets**.

Если выпусков пока нет, установщик ещё не опубликован. Архивы **Source code** не являются установщиками приложения.

## Возможности

- Создание конспектов из документов и расшифровок аудио и видео.
- Генерация учебных карточек с вопросами и ответами для самопроверки.
- Обработка длинных материалов по частям с сохранением промежуточных результатов.
- Формирование конспекта с учётом разделов и порядка исходного материала.
- Добавление извлечённых иллюстраций и кадров в приложение к конспекту с указанием источника.
- Локальная обработка или подключение OpenAI-совместимого сервиса и GigaChat.

Качество результата зависит от исходного материала и выбранной модели. Сверяйте важные определения и выводы с оригиналом. Сохранение иллюстраций не означает, что локальная текстовая модель анализирует их содержание.

## Системные требования

Целевая минимальная конфигурация для стандартного локального режима:

| Компонент | Требование |
| --- | --- |
| Операционная система | Windows 10 или Windows 11, 64 бит |
| Процессор | Intel Core i3-1215U — целевой ориентир |
| Оперативная память | 8 ГБ |
| Графика | Встроенная Intel UHD Graphics; отдельная видеокарта не требуется |
| Свободное место | От 6 ГБ для установки, дополнительно — место под материалы и результаты |
| Интернет | Для первоначальной загрузки моделей, проверки обновлений и облачных сервисов |

Скорость на указанной конфигурации пока не измерена. Обработка больших книг и длительных записей на процессоре может занимать значительное время.

## Установка

1. Скачайте **StudyAssistant-Setup.exe** из нужного выпуска.
2. Запустите файл и следуйте указаниям мастера.
3. Для стандартной локальной работы оставьте выбранными **Qwen3-1.7B** и **Whisper Base**.
4. Дождитесь загрузки моделей и завершения установки.
5. Запустите **StudyAssistant** с ярлыка.

Устанавливать Python или вручную распаковывать компоненты не нужно.

Стандартная комплектация использует:

- **Qwen3-1.7B Q8_0** — для конспектов и карточек; загрузка около 1,83 ГБ.
- **Whisper Base** — для распознавания речи; загрузка около 148 МБ.

При первоначальной установке моделей скачивается около **2 ГБ**. Установщик проверяет контрольные суммы загрузок. После установки моделей локальная обработка работает без интернета и API-ключей.

Whisper Medium — дополнительный, более требовательный вариант распознавания речи. Для минимальной конфигурации используйте Base.

## Обновления

Перед обновлением закройте StudyAssistant и запустите установщик новой версии. Мастер предлагает:

- **Обновить основную версию** с сохранением пользовательских данных.
- **Установить рядом** со старой версией, создав отдельные настройки и карточки.
- **Оставить текущую версию** и выйти из установки.

При установке рядом старые карточки автоматически не переносятся. Перед первым запуском обновлённой основной версии приложение создаёт резервную копию базы данных и настроек.

Начиная с версии 0.2.1, уведомление о найденном обновлении показывает описание изменений и кнопки **«Обновить»** и **«Не сейчас»**. Кнопка «Обновить» открывает страницу выпуска для скачивания установщика; установка не запускается автоматически.

> Проверка обновлений работает только в сборках, подключённых к доступному каналу выпусков. Ранние сборки могут обращаться к закрытому репозиторию. Для перехода на новый канал такую сборку потребуется один раз обновить вручную.

## Локальная и облачная обработка

В локальном режиме материал обрабатывается на компьютере, API-ключи и платный бюджет токенов не требуются. Подготовка медиа и запуск моделей выполняются без всплывающих консольных окон.

При выборе облачного сервиса материалы передаются выбранному провайдеру. Для работы потребуется собственный доступ; условия использования и оплаты определяются провайдером. Инструкции по подключению доступны в приложении.

## Если возникла проблема

В обращении укажите версию StudyAssistant, версию Windows, объём ОЗУ, выбранный режим обработки, тип исходного файла и действия перед ошибкой. Приложите текст ошибки или снимок экрана. Не публикуйте API-ключи и конфиденциальные учебные материалы.

Описание изменений и особенности конкретной версии находятся на странице соответствующего [выпуска](https://github.com/atroid25/StudyAssistant-releases/releases).
