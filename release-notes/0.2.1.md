# StudyAssistant 0.2.1

Подключён публичный канал обновлений StudyAssistant-releases.

- В приложении добавлено окно с текущей и новой версиями, описанием изменений и кнопками «Обновить» / «Не сейчас».
- «Обновить» открывает страницу нужного выпуска для загрузки EXE.
- Проверка версий в приложении и установщике переведена на публичный репозиторий.
- Исправлен недоступный адрес загрузки FFmpeg при сборке; проверка контрольной суммы сохранена.

Для перехода с 0.2.0 установите новую версию вручную. Настройки и карточки основной установки сохраняются.
