# StudyAssistant 0.2.2

Обработка изображений по порциям и автоматическое предложение обновлений при доступной сети.

## Что изменилось

- Убрана техническая строка про «лимит 12» и количество кадров на странице конспекта.
- Изображения обрабатываются порциями: до 120 изображений и до 64 МБ данных за один проход. При достижении лимита приложение предупреждает, сохраняет текущий результат и позицию продолжения.
- Следующая порция получает новый лимит и сохраняется отдельным файлом рядом с основным конспектом. Текст, карточки и распознавание речи повторно не генерируются. Для продолжения нужен исходный файл без изменений.
- Кадры видео выбираются по всей записи примерно раз в минуту, без общего ограничения в 120 кадров на весь источник. Лимит применяется к одной порции.
- Добавлена фоновая проверка обновлений при запуске. При недоступной сети повтор выполняется примерно через минуту, после успешной проверки — раз в 30 минут. Ошибки фоновой проверки не прерывают работу.
- При появлении новой версии показываются описание изменений и кнопки «Обновить» / «Не сейчас». Повторное предложение той же версии в текущем сеансе не показывается. Во время обработки материалов уведомление откладывается.
- Описания выпусков и таблица версий в публичном репозитории обновляются автоматизацией GitHub Actions.

## Установка и обновление

Скачайте StudyAssistant-Setup.exe из Assets. Закройте приложение и запустите установщик. Можно обновить основную версию с сохранением данных или установить новую рядом.

Целевая минимальная конфигурация: Windows 10/11 x64, Intel Core i3-1215U, 8 ГБ ОЗУ, Intel UHD Graphics, от 6 ГБ свободного места плюс место для материалов. По умолчанию используются Qwen3-1.7B и Whisper Base; первоначальная загрузка моделей — около 2 ГБ. Скорость на указанном компьютере пока не измерена.

Переход с 0.2.0 выполняется вручную: эта версия обращается к прежнему закрытому каналу. Кнопка «Обновить» открывает страницу выпуска; установщик не запускается автоматически.
