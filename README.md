# StudyAssistant

Приложение для Windows, которое создаёт конспекты и учебные карточки из документов, аудио и видео. Этот репозиторий содержит установщики и описания выпусков.

## Скачать и установить

Откройте [Releases](https://github.com/atroid25/StudyAssistant-releases/releases), выберите стабильный выпуск и скачайте EXE из **Assets**. Запустите установщик и следуйте мастеру. Архивы Source code не являются установщиками приложения.

Для локальной работы по умолчанию устанавливаются Qwen3-1.7B и Whisper Base. Первоначальная загрузка моделей — около 2 ГБ, после неё локальная обработка работает без API-ключей и интернета. При использовании облачных сервисов материалы передаются выбранному провайдеру.

## Требования

Целевая минимальная конфигурация: Windows 10/11 x64, Core i3-1215U, 8 ГБ ОЗУ, Intel UHD Graphics, от 6 ГБ свободного места плюс место для материалов. Производительность на указанном компьютере пока не измерена.

## Обновления

Начиная с 0.2.1 приложение подключено к публичному каналу и показывает описание найденного обновления. В 0.2.2 добавлена фоновая проверка при запуске с повтором после недоступности сети. «Обновить» открывает страницу загрузки; запуск установщика остаётся за пользователем.

С версии 0.2.0 нужно один раз обновиться вручную. Мастер позволяет обновить основную версию с сохранением данных или установить новую рядом с отдельным профилем.

## Для выпуска новой версии

1. Добавьте описание в `release-notes/НОМЕР.md`, например `release-notes/0.2.2.md`.
2. Создайте выпуск с тегом `vНОМЕР`, прикрепите соответствующий проверенный EXE и опубликуйте его.
3. Дождитесь успешного выполнения **Sync release descriptions**: описание будет перенесено в выпуск, а README получит актуальную таблицу.

Автоматизация не публикует черновики, не загружает установщики и не меняет их содержимое. Если отдельного файла описания нет, сохраняется текст, введённый на странице выпуска. Ручной повтор доступен в Actions → Sync release descriptions → Run workflow.
